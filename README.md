# 🏫 School Safety Risk Scenario Analysis
### 다차원 위험 시나리오 분석 기반 학교안전 예방처방 및 효과환류 체계

> **사고를 세는 데서, 예방을 설계하는 데까지**  
> 2021~2025년 학교안전사고 데이터를 다차원적으로 분석하여  
> 학교가 우선적으로 점검해야 할 위험 시나리오를 도출하고,  
> 이를 실제 예방조치와 결과 환류로 연결하는 **SAFE-Rx** 체계를 제안한 프로젝트입니다.

---

## 📌 Project Overview

기존 학교안전사고 분석은 주로  
**어떤 사고가 많이 발생했는가**를 확인하는 데 초점이 맞춰져 있습니다.

하지만 실제 학교 현장에서 예방조치를 결정하기 위해서는

- 어떤 학교급에서
- 어떤 학생이
- 언제
- 어디에서
- 어떤 활동을 하다가
- 어떤 사고를 경험했는지

를 함께 살펴볼 필요가 있습니다.

본 프로젝트에서는 학교안전사고를 단일 항목이 아닌  
**여러 조건이 결합된 하나의 구체적인 위험 장면**으로 정의했습니다.

이를 통해 다차원 위험 시나리오를 도출하고,

> **위험 탐지 → 현장 확인 → 예방조치 선택·시행 → 결과 기록 → 환류**

로 이어지는 학교안전 예방체계 **SAFE-Rx**를 설계했습니다.

---

## 🎯 Research Questions

본 프로젝트는 다음 세 가지 질문에서 출발했습니다.

1. **사고가 가장 많은 학교급과 규모 대비 사고부담이 가장 높은 학교급은 같은가?**
2. **학교급·성별·학년·시간·장소·활동을 함께 고려하면 어떤 반복적인 위험상황이 나타나는가?**
3. **분석을 통해 발견한 위험을 실제 학교의 예방활동과 어떻게 연결할 수 있는가?**

## 2️⃣ Multidimensional Association Rule Mining

사고를 단순 집계하지 않고  
**상황조건 → 사고결과** 형태의 연관규칙으로 분석했습니다.

### Antecedent — 상황조건

```text
학교급
성별
학년군
사고시간
사고장소
사고당시활동
학기맥락
```

### Consequent — 사고결과

```text
사고형태
사고부위
```

예를 들어,

```text
중학교 + 여학생 + 체육 + 농구
                ↓
손가락 상해 + 움직이는 물체와 부딪힘
```

과 같은 조합을 하나의 위험 시나리오 후보로 정의했습니다.

분석에는 `FP-Growth` 기반 빈발항목 탐색과  
Association Rule Mining을 사용했습니다.

## 📐 Scenario Selection Criteria

위험 시나리오 후보를 선별하기 위해 다음 기준을 적용했습니다.

| Metric | Threshold | Meaning |
|---|---:|---|
| Support | ≥ 0.50% | 전체 사고 중 해당 시나리오가 차지하는 비율 |
| Confidence | ≥ 30.0% | 해당 상황조건에서 특정 사고결과가 발생한 비율 |
| Lift | ≥ 1.50 | 전체 평균 대비 해당 결과가 얼마나 집중되는지 |

조건 순서만 다르거나 상·하위 관계로 사실상 동일한 규칙을 정리한 결과,

### **최종 457개 위험 시나리오**

를 도출했습니다.

> Support, Confidence, Lift는 개인별 사고확률이나 사고원인을 의미하지 않습니다.  
> 학교가 우선적으로 확인해야 할 위험상황을 좁히기 위한 분석지표로 활용했습니다.

## 3️⃣ Population Adjustment

단순 사고건수만으로 비교하면  
학교급과 성별에 따른 집단 규모 차이가 반영되지 않습니다.

이를 보완하기 위해 두 가지 지표를 함께 계산했습니다.

### 학생 수 보정

```text
5개년 연평균 사고 신고건수
────────────────────── × 10,000
5개년 연평균 학생 수
```

→ **학생 1만 명당 연평균 사고 신고건수**

### 학교 수 보정

```text
5개년 연평균 사고 신고건수
──────────────────────
5개년 연평균 학교 수
```

→ **학교 1개교당 연평균 사고 신고건수**

---

## 📈 Key Result 01
### 사고 규모와 상대적 사고부담은 달랐다

절대 사고건수에서는 **초등학교**가 가장 높은 비중을 차지했습니다.

```text
초등학교   412,460건   50.8%
중학교     264,733건   32.6%
고등학교   135,170건   16.6%
```

그러나 학생 수와 학교 수를 반영하면 결과가 달라졌습니다.

| 학교급 | 학생 1만 명당 연평균 신고건수 | 학교 1개교당 연평균 신고건수 |
|---|---:|---:|
| 초등학교 | 315.77 | 13.39 |
| **중학교** | **393.41** | **16.25** |
| 고등학교 | 205.61 | 11.39 |

즉,

> **사고가 가장 많이 발생한 학교급과  
> 규모 대비 사고부담이 가장 높은 학교급은 서로 달랐습니다.**

따라서 절대 사고규모와 상대적 사고부담을 함께 고려할 필요가 있음을 확인했습니다.

---

## 🚨 Key Result 02
### 457개 위험 시나리오에서 5가지 대표 유형 선정

위험을 하나의 지표로만 판단하지 않고

- 사고 규모
- 학생 규모 대비 부담
- 학교 규모 대비 부담
- 특정 결과의 집중도
- 최근 변화

라는 서로 다른 관점에서 대표 사례를 선정했습니다.

### ① Volume — 규모형

**걷기·뛰기·오르내리기 → 넘어짐**

```text
5개년 사고건수      215,097건
Support             26.48%
Confidence          52.37%
Lift                1.98
```

5개년 및 전국 17개 시·도에서 반복적으로 확인된  
**전국 공통 생활·이동 위험**입니다.

---

### ② Density — 밀도형

**중학교 여학생 → 손가락 상해**

```text
5개년 사고건수                 35,171건
학생 1만 명당 연평균 신고건수   107.48
Support                         4.33%
Confidence                     33.57%
Lift                            1.53
```

전체 위험 시나리오 중  
**학생 규모 대비 사고부담이 특히 높은 사례**입니다.

---

### ③ School Burden — 학교부담형

**중학교 체육활동 → 손가락 상해**

```text
5개년 사고건수                 46,147건
학교 1개교당 연평균 신고건수      2.82
Support                         5.68%
Confidence                     32.99%
Lift                            1.50
```

학교급이 명시된 위험 시나리오 가운데  
**학교 1개교당 사고 신고부담이 가장 높은 유형**으로 확인했습니다.

---

### ④ Lift — 특이형

**중학교 여학생 + 체육 + 농구  
→ 손가락 상해 + 움직이는 물체와 부딪힘**

```text
5개년 사고건수      4,357건
Support              0.54%
Confidence          39.81%
Lift                 5.09
```

절대 건수는 상대적으로 작지만  
특정 조건이 결합될수록 결과가 강하게 집중되는 사례입니다.

---

### ⑤ Trend — 최근변화형

**고등학교 남학생 + 체육활동 → 발목 상해**

```text
5개년 사고건수                 15,030건
학생 1만 명당 연평균 신고건수    46.69
Support                         1.85%
Confidence                     31.45%
Lift                            1.57
```

학생 수 보정 신고건수는

```text
2021년 43.29
        ↓
2025년 48.93
```

으로 약 **13.0% 증가**하여  
향후 추이를 지속적으로 확인할 필요가 있는 유형으로 분류했습니다.

## ✅ Validation

발견한 규칙이 특정 연도나 일부 지역에서만 나타난 결과인지 확인하기 위해  
여러 단계의 검증을 수행했습니다.

### 01. 연도별 반복성

```text
5개 연도 모두 관찰
3~4개 연도 반복 관찰
최근 연도 집중
```

등으로 시나리오의 지속성을 확인했습니다.

### 02. 지역 반복성

각 시·도에서

```text
사고건수 ≥ 100건
지역 내 Support ≥ 0.50%
```

을 기준으로 반복 여부를 확인했습니다.

### 03. Train / Test 기간 분할

```text
Train : 2021~2024
Test  : 2025
```

2021~2024년 자료에서 확인된 대표 시나리오가  
2025년에도 최소 분석기준을 충족하는지 재검증했습니다.

### 04. Sensitivity Analysis

분석기준을 한 단계씩 강화했습니다.

```text
Support     0.50% → 1.00%
Confidence 30.0% → 35.0%
Lift        1.50  → 1.80
```

강화된 기준에서 유지되는 규칙의 수와  
대표 시나리오의 변화를 비교해 결과의 안정성을 점검했습니다.

# 🛡 SAFE-Rx
### School Accident Feedback & Evidence-based Risk Prescription

분석의 목표를 단순한 위험 발견에서 끝내지 않고  
실제 학교의 예방활동으로 연결하기 위해 제안한 체계입니다.

```text
① 위험 시나리오 탐지
          ↓
② 학교 현장 확인
          ↓
③ 예방조치 후보 검토
          ↓
④ 조치 선택·시행
          ↓
⑤ 결과 기록
          ↓
⑥ 다음 안전계획으로 환류
```

학교가 검토할 예방조치는 다음 6개 영역으로 구성했습니다.

```text
교육·행동
시설·공간
시간·운영
이동동선
장비
지도·감독
```

중요한 점은 통계적으로 발견된 위험을  
곧바로 사고의 원인으로 단정하지 않는다는 것입니다.

학교 담당자가 실제

- 사고 발생장소
- 시설과 장비 상태
- 활동 방식
- 지도 여건
- 인력
- 공간
- 예산

을 확인한 후 적용할 조치를 선택하도록 설계했습니다.

## 🔄 Effect Feedback

예방조치를 시행한 뒤에는 다음 정보를 기록합니다.

```text
대상 위험 시나리오
적용 기간 및 범위
시행한 조치
조치 이행 정도
이후 사고 변화
선택 근거
```

조치의 효과 역시 단기간의 사고 감소만으로 판단하지 않습니다.

```text
1. 관찰
   한 학교·한 기간의 변화 확인

2. 반복 확인
   동일 학교의 여러 기간 또는
   유사 학교에서 같은 변화가 반복되는지 확인

3. 확산 검토
   충분한 근거가 축적된 경우
   다른 학교로의 확대 검토
```

이를 통해 시행 결과를 다음 위험분석과 안전계획의 근거로 다시 활용하는  
**효과환류 구조**를 제안했습니다.

### 1. Clone

```bash
git clone <YOUR_REPOSITORY_URL>
cd school-safety-risk-scenario-analysis
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Prepare Data

분석에 사용되는 원자료는 `data/` 디렉터리에 위치시킵니다.

데이터 이용 및 재배포 가능 여부는 원 제공기관의 정책을 확인해야 합니다.

### 4. Run Pipeline

분석 순서에 따라 실행합니다.

```bash
python src/01_validate_school_level_heterogeneity.py
python src/02_build_analysis_datamart.py
python src/03_mine_risk_scenarios.py
python src/04_adjust_population_denominators.py
python src/05_select_final_risk_scenarios.py
python src/06_validate_reproducibility.py
python src/07_build_final_scenario_summary.py
```

생성된 분석 결과는 `outputs/`에 저장됩니다.

## ⚠️ Interpretation & Limitations

본 프로젝트에서 도출한 위험 시나리오는  
**사고원인이나 개인별 사고확률을 예측하는 모델이 아닙니다.**

학교안전사고 기록에는

- 시설 상태
- 학생 개인의 숙련도
- 실제 활동 참여시간
- 당시 지도방식
- 비사고 학생 정보

등이 포함되어 있지 않기 때문에  
통계적 연관관계를 직접적인 사고원인으로 해석할 수 없습니다.

따라서 결과는

> **학교가 우선적으로 현장을 확인해야 할 상황을 좁혀주는 의사결정 지원정보**

로 해석했습니다.

## 🤖 About AI

본 데이터 분석 과정 자체에서는  
생성형 AI를 분석기법으로 사용하지 않았습니다.

SAFE-Rx에서 제안하는 AI의 역할은  
최종 예방조치를 자동으로 결정하는 것이 아니라,

```text
위험 시나리오
      ↓
공식 안전지침 및 공개 예방자료 검색
      ↓
근거와 예방조치 후보 정리
      ↓
학교 담당자의 현장 확인 및 최종 선택
```

을 지원하는 **의사결정 보조 역할**입니다.

## 🚀 Future Work

SAFE-Rx는 현재 분석 및 체계 설계 단계입니다.

향후에는 일부 학교를 대상으로

- 실제 현장 확인 가능성
- 예방조치 선택 및 기록 가능성
- 조치 전·후 사고 변화
- 동일 학교에서의 반복 확인
- 유사 학교에서의 재현성

을 검증할 필요가 있습니다.

충분한 현장 근거가 축적된 이후에만  
다른 학교로의 확대 적용을 검토하는 것을 목표로 합니다.
